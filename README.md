# Free PDF Tools - website guide (Roman Urdu)

## Is mein kya hai
- `index.html`: poori website (Merge, Split/Extract, JPG to PDF, Rotate). Sab kuch user ke browser mein hota hai, aap ke server ka koi kharcha nahi.
- `privacy.html`: Privacy Policy (AdSense ke liye zaroori). Isme `apna-email@example.com` apni email se badal dein.

## Free hosting (phone se bhi ho jata hai)
1. github.com par account banayein, naya repository banayein, dono files upload karein.
2. Repository Settings > Pages mein branch `main` chunein. Aap ko free link mil jayega.
   (Ya Cloudflare Pages / Netlify Drop par files daal dein.)
3. Apna domain lena behtar hai (Namecheap/GoDaddy, ~1000-1500 Rs/saal). AdSense custom domain par zyada asaani se approve hota hai.

## Paise kaise kamayein (AdSense)
1. Website live karein, aur ek `About` aur `Contact` page bhi shamil karein.
2. adsense.google.com par apni site add karein. Wo ek script dega: usay `index.html` ke `<head>` mein paste karein.
3. Approval mein hafte lag sakte hain. Approve hone ke baad `Ad space` wali jagah par ad code paste karein.
4. Traffic ke liye: har tool ka alag page banayein (merge-pdf.html, jpg-to-pdf.html), unka description likhein, aur Google Search Console mein site daalein.

## Honest baat
Kamai traffic par depend karti hai. Pehle 2-3 mahine aksar kuch nahi aata, phir bhi koi guarantee nahi. Naye tools (Compress, PDF to JPG, etc.) barhate rahenge to traffic barhegi.
